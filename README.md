# BPLog

A blood pressure tracking app designed for elderly users — large text, large buttons, no clutter.

Built by [Hakamata Software](https://www.hakamata-soft.com/) as a personal project.

---

## Features

- Log systolic, diastolic, and pulse — AM and PM each day
- Monthly list view for sharing with your doctor
- Line graph with personal target lines
- Supports Japanese and English (auto-detected from device settings)

## Free & Private

- **Completely free** — no ads, no subscriptions, no in-app purchases
- **No internet connection required** — all data stays on your device
- **No data collection** — nothing is transmitted anywhere

## Tech Stack

- React Native (Expo SDK 56)
- TypeScript
- AsyncStorage for local persistence
